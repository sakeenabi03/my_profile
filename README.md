# Sakeena Bi Portfolio

A responsive, static portfolio built with Vite and React. Project descriptions and links reflect the public GitHub repositories linked on the site.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`. Import this repository into Vercel; it detects Vite automatically and uses `npm run build` with `dist` as the output directory.
